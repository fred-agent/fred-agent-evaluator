The evaluation application is deployed in namespace {{ $ns }}.

On Weaver, a platform administrator opens Admin > Applications and registers:
  Logical name: evaluation
  Entry permission (entry_permission): run_evaluations
  Display name: Evaluation / Évaluation
  Version: {{ trimPrefix "v" .Chart.AppVersion }}
  Icon: fact_check
  UI upstream: {{ $ui }}
  API upstream: {{ $api }}

Create the registration disabled, then enable it after checking the upstreams.
An organization Owner authorizes evaluation for their organization; local space
policy may restrict it further. Only collective spaces support applications.
Application availability does not grant evaluation business permissions.

Control Plane stores the registration in SQL. Do not add application_sources,
FRONTEND_APPLICATIONS_JSON or enableApplications to Weaver's Helm values.
The existing Fred gateway forwards /apps/* and /app-services/* to Control Plane.
No Fred restart is required when changing a registration.

The UI accepts messages only from {{ .Values.ui.hostOrigin }}.
Swift retains its existing Helm registration and team-grant workflow.
